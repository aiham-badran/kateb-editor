      Creates a Block instance with simplified options.

      Parameters

      • name: string

        Unique block name (e.g., 'paragraph', 'custom').

      • spec: NodeSpec

        ProseMirror node specification (defines content, attributes, and DOM mapping).

      • options: {
            allowedMarks?: string[];
            keymap?: Record<string, Command>;
            searchTerms?: string[];
            slashLabel?: string;
            toolbarButtons?: ToolbarButton[];
        } = {}

        Optional settings for the block.

        • OptionalallowedMarks?: string[]

          List of mark names allowed inside this block. If undefined, all marks are allowed.

        • Optionalkeymap?: Record<string, Command>

          Keymap object (shortcut → command) specific to this block.

        • OptionalsearchTerms?: string[]

          Additional keywords for slash menu search.

        • OptionalslashLabel?: string

          If provided, a slash menu item with this label will be created.

        • OptionaltoolbarButtons?: ToolbarButton[]

          Array of toolbar buttons associated with this block.

      Returns Block

      A new Block instance.

      Example

      const paragraph = createBlock('paragraph', {
        content: 'inline*',
        group: 'block',
        toDOM: () => ['p', 0]
      }, {
        slashLabel: 'فقرة',
        allowedMarks: ['strong', 'em']
      });
