# دليل المساهمة في Kateb Editor

شكراً لاهتمامك بالمساهمة في Kateb Editor! نحن نرحب بمساهمات المجتمع لتحسين المكتبة.

## كيفية المساهمة

### الإبلاغ عن مشكلة (Issue)

- تأكد أولاً من عدم وجود مشكلة مشابهة مفتوحة أو مغلقة.
- استخدم القالب المخصص للمشكلات وقدم وصفاً واضحاً مع خطوات إعادة الإنتاج.
- أضف لقطة شاشة أو مقطع فيديو إن أمكن.

### طلب إضافة ميزة (Feature Request)

- اشرح المشكلة التي تحلها الميزة المقترحة.
- قدم أمثلة على كيفية استخدامها.
- إذا كان التغيير كبيراً، ناقشه في قناة المناقشة أولاً.

### إرسال طلب سحب (Pull Request)

1. **اشترك في المشروع** – fork المستودع وأنشئ فرعاً جديداً.
2. **اتبع نمط الكود** – استخدم TypeScript مع JSDoc للتوثيق.
3. **اكتب الاختبارات** – أضف اختبارات لتغطية التغييرات الجديدة.
4. **شغّل الاختبارات** – تأكد من أن `npm test` تمر جميعها.
5. **التزم بالتغييرات** – اكتب رسالة commit واضحة (مثلاً: `feat: add support for custom blocks`).
6. **أرسل الطلب** – إلى الفرع الرئيسي (`main` أو `master`).

## معايير الكود

- **TypeScript**: استخدم الأنواع بدقة، وتجنب `any` كلما أمكن.
- **JSDoc**: وثّق جميع الدوال والكلاسات والواجهات العامة باللغة الإنجليزية.
- **التنسيق**: استخدم `Prettier` و `ESLint` مع الإعدادات الافتراضية للمشروع.
- **الاختبارات**: أضف اختبارات باستخدام Vitest لكل ميزة جديدة.

## هيكل المشروع

src/
├── core/ # النواة (SchemaBuilder, Editor, Blocks, Marks)
├── engine-arabic/ # المحرك العربي (RTL, punctuation, direction)
├── ui/ # واجهات المستخدم (Toolbar, SlashMenu)
├── blocks/ # البلوكات المضمنة (paragraph, heading)
├── marks/ # العلامات المضمنة (strong, em)
└── index.ts # نقطة الدخول

## التواصل

- GitHub Issues: للإبلاغ عن المشكلات وطلبات الميزات.
- Discussions: للمناقشات العامة والاستفسارات.
