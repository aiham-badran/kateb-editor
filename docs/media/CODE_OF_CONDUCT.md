# قواعد السلوك (Code of Conduct)

## التزامنا

نحن، كمشاركين ومساهمين في مشروع **Kateb Editor**، نلتزم بتوفير بيئة خالية من التحرش للجميع، بغض النظر عن العمر، الحجم، الإعاقة، العرق، الهوية الجنسية، مستوى الخبرة، الجنسية، المظهر الشخصي، الدين، أو التوجه الجنسي.

## معاييرنا

السلوكيات الإيجابية التي تساهم في بيئة إيجابية تشمل:

- استخدام لغة مرحبة وشاملة.
- احترام وجهات النظر والخبرات المختلفة.
- قبول النقد البناء بلطف.
- التركيز على ما هو أفضل للمجتمع.
- إظهار التعاطف مع أعضاء المجتمع الآخرين.

السلوكيات غير المقبولة تشمل:

- استخدام لغة أو صور تحرش جنسي.
- التصيد (trolling) والتعليقات المهينة أو السياسية.
- التحرش العلني أو الخاص.
- نشر معلومات شخصية للآخرين دون إذن صريح.
- أي سلوك غير مهني أو غير لائق.

## مسؤولياتنا

يتحمل مشرفو المشروع مسؤولية توضيح معايير السلوك المقبول، واتخاذ إجراءات تصحيحية مناسبة وعادلة في حالة أي سلوك غير مقبول.

## النطاق

تسري قواعد السلوك هذه في جميع مساحات المشروع (المنتدى، GitHub، وسائل التواصل)، وكذلك عندما يمثل فرد المشروع في الأماكن العامة.

## التبليغ عن انتهاك

إذا تعرضت لسلوك غير مقبول، أو لاحظت أي شخص يقوم بذلك، يرجى التواصل مع فريق المشروع عبر [email@example.com] أو عبر GitHub Issues بشكل خاص. سنحقق في جميع البلاغات بسرية تامة.

## الإسناد

هذه القواعد مقتبسة من [Contributor Covenant](https://www.contributor-covenant.org)، الإصدار 2.1.
